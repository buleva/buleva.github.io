App Code einlösen

Folgen Sie diesen 5 Schritten, um Ihren Code einzulösen.

Schritt 1

Öffnen Sie den App Store auf Ihrem iPhone

Schritt 2

Tippen Sie oben rechts auf das Profil-Icon.

Schritt 3

Klicken Sie auf"Karte oder Code einlösen".

Schritt 4

Klicken Sie auf "Code manuell einlösen".

Schritt 5

Geben Sie den Code ein und tippen Sie auf "Einlösen".

Schritt 6

Klicken Sie auf "Einlösen & Installieren".
