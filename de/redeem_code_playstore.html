Google Play Code einlösen

Folgen Sie diesen 6 Schritten, um Ihren Code einzulösen.

Schritt 1

Öffnen Sie die "Pitch"-App auf Ihrem Android-Gerät.

Schritt 2

Tippen Sie oben rechts auf das Profil-Icon.

Schritt 3

Klicken Sie auf den "Abonnieren"-Button.

Schritt 5

Klicken Sie auf die aktuelle Zahlungsmethode

Schritt 4

Wählen Sie dann "Code einlösen".

Schritt 5

Geben Sie den Code ein und tippen Sie auf "Einlösen".
